# Assistente Shopee Pro — página V4

Arquivos separados:
- `index.html` — estrutura e copy
- `styles.css` — visual (cores Shopee e interface de IA no bloco final `V4`)
- `script.js` — checkout, assets, barra mobile e seleção de exemplos ilustrativos
- `assets/` — pasta de imagens

## Imagens
Adicione as imagens usando os nomes exatos:
- `assets/demonstracao-ia.webp`
- `assets/prova-01.webp`
- `assets/prova-02.webp`
- `assets/prova-03.webp`
- `assets/prova-04.webp`

## Checkout
Edite `script.js` e preencha `CONFIG.checkoutUrl` com a URL HTTPS do checkout Kiwify.

## Importante
A simulação visual do topo é uma **demonstração ilustrativa**, não uma interface própria nem um chat ao vivo. Os três botões de exemplo alternam textos estáticos. O produto é acessado separadamente pelo ChatGPT.

Confirme oferta, política de entrega, suporte, reembolso e disponibilidade do GPT antes de publicar.
